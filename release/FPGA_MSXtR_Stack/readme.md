# 既知のバグ

(1) カートリッジスロットの D0～D7 の HiZ ができない 
　→ バス競合で壊れるのを避けるために、I/O Read時は CPU→Cartridge 固定にしてるため、Readをしてしまう 
　　ような I/Oカートリッジは、基板を直すまで使用禁止。 
 
(2) スロットの A15, A14 が FlashROM の A15, A14 と共通 
　→ 明らかに分けておけばよかった。次の基板で直す。 
 
(3) SerialSRAM 512KB x 4 
　→ SerialSRAM 4MB x 1 で良かったはずだ。パラレルSRAM 4MB の方がいいが、無茶苦茶高いのでありえない。 
 
(4) VDP と Pico のダイレクト通信パスをつけ忘れた 
　→ メンテナンスメニューや、ディスクイメージ交換などの UI のオーバーレイ表示をする予定だったが、 
　　特殊なトリックなどを使わないと、現在の基板ではできない。特殊なトリック回路なんて設計したくないので 
　　次で修正予定。 

# 書き込み手順
FPGA_MSXtR_CPU_Stack.fs を TangPrimer25K に Dock を使って書き込み
↓ 
CPU Stack Board に取り付け 
 
FPGA_MSXtR_VDP_Stack.fs を VDP Stack Board に取り付けられた TangNano20K に書き込み 
 
RasPiPico の bootボタンを押しながら USB で PC と繋ぎ、 
ストレージデバイスと認識されるので fpga_msxtr_controller.uf2 をそこにコピーして 
書込み 
 
microSDカードに /bios/msxtr.rom, /bios/kanji.rom を置く 
 
CPU Stack Board と VDP Stack Board と Cartridge Slot Board とキーボードを接続して、 
Pico の USB端子に USBケーブルをつなぎ、PC と繋げる 
 
PC では シリアルターミナルを起動（TeraTerm）しておく 
 
MENUキーを押して Pico に切り替える（ターミナルに Pico に切り替えた旨表示される） 
 
フルキーの [4] を押すと BIOS が書き込まれる 
 
USBケーブルを取り外し、電源用 USB-C に電源を供給し、電源スイッチを入れれば起動。
