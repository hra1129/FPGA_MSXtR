# 命令セットの拡張
Z80命令に加えて、R800独自の命令が追加されている。
8bit×8bit→16bitおよび16bit×16bit→32bitの精度を持つ乗算命令をサポート。
Z80の未定義命令もR800では定義されている。

命令表は下記のサイトに詳しく書かれている。
https://d4.princess.ne.jp/msx/datas/R800UM/r800op.html

Z80との微妙な挙動の違いについては、下記のサイトに詳しく書かれている。
https://github.com/uniabis/msxrawl/tree/main/r800chk

M1サイクル時には、Z80のときは 1ウェイト入れていたが、R800 ではノーウェイト。
正し、下記のケースでは、Z80 と同じ速度になるように調整する。
- SLOT#1 または SLOT#2 に対するメモリアクセス
- FPGA外の I/Oポートへのアクセス

リフレッシュのステートは、通常なし。1ms を数えるカウンターを内蔵し、
1ms数えた後もリフレッシュをしていなければ、次の命令を始める前にリフレッシュする。
slot_rfsh_n の間隔は、Z80 と同じで、アドレス信号の下位8bit に R レジスタの値を出すのも同じである。

メモリやI/Oへのアクセスが無いマシンサイクルは、極力短い時間で終了する。
