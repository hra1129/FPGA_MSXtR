# 内容
ASCII16形式のメガROM。
512KB ですべてのバンクが下記のような内容。
	(1) 画面モードを SCREEN1 にする
	(2) バンク番号を示すメッセージを表示する
	(3) 6 frame 程度待機する
	(4) 次のバンクへ切り替える
	(5) (2)へ戻る

(4) のバンク切り替えで実行中のコードが切り替わってしまうが、
切り替わった先のバンクも同じ内容が書かれているので問題なく動作する。
バンク切り替えが正常に行われていれば、バンク番号が順次インクリメント
されたメッセージが表示されるだけのシンプルな動作になる。
一方で、バンク切り替えが正常に行われていなければ、バンク番号の表示が
インクリメントではない別の動きをする。
それを観察するためのテストROMである。
